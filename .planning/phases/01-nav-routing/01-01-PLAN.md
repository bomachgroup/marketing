<objective>
Wire the sidebar to the router and establish the shared navigation module.

Purpose: The sidebar is the primary navigation surface. Today `handleNavClick` only mutates store state (`setCurSc`) — the URL never changes and screens don't actually route. This plan makes the sidebar drive the router (mirroring HTML `goSc`), derives the active highlight from the URL, lands role switches on the role's first nav screen (mirroring HTML `setRole`), and adds per-screen `document.title` (mirroring `goSc`'s title update). It also creates `src/navigation.ts` — the single shared module every subsequent plan imports.
Output: `src/navigation.ts`, rewired `Sidebar.tsx`, `AppShell.tsx` with title effect.
</objective>
